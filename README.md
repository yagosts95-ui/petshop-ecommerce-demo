# D' Paula Casa do Criador — Demo

Demo responsiva de e-commerce para apresentação comercial.

## Escopo da demo
- Loja responsiva desktop/mobile
- Categorias e busca
- Catálogo de produtos
- Carrinho demonstrativo
- Painel administrativo em `/admin`
- Pedidos e atualização de status
- Controle demonstrativo de estoque

## Rodar localmente
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Próxima etapa: conectar Supabase e Cloudflare Pages.
